# Design Patterns & their implementations

This project demonstrates the design patterns using a class-based approach in TypeScript.

## 🛠 How to Run

### 1. Compile the TypeScript file

Use the TypeScript compiler (`tsc`) to compile the `.ts` file to a `.js` file.

```bash
tsc singleton.ts
```

### 2. Run the compiled JavaScript file with Node.js

```bash
node singleton.js
```
